## ⚠️ Important Note About Problem Numbers

> **Please read this before navigating the repository.**

The **problem names/titles in this repository are correct**, but **some folder names contain incorrect LeetCode problem numbers**.

This happened because of a **LeetCode extension numbering glitch** while pushing the solutions to GitHub.

For example:

```text
1019-squares-of-a-sorted-array
```

The problem name **"Squares of a Sorted Array"** is correct, but the `1019` in the folder name is incorrect.

Similarly, some other folders may have mismatched numbers.

### How to verify the correct problem

The **individual ****`README.md`**** files inside each problem folder contain the correct LeetCode problem link**.

Therefore:

**Problem Name → Correct** ✅
**Solution → Correct problem** ✅
**LeetCode Link → Correct** ✅
**Folder Number → May be incorrect for some problems** ⚠️

The incorrect numbers are only a repository naming issue and **do not indicate that the solutions correspond to the wrong problems**.
